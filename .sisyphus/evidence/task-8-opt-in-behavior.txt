TASK 8: OPT-IN/OPT-OUT BEHAVIOR VERIFICATION
=============================================

Date: 2026-02-18
File: supabase/functions/process-mention/index.ts

OPT-IN BEHAVIOR
---------------

When agentic_opt_in = TRUE:

1. CREATOR LOOKUP (lookupVerifiedCreator)
   - Fetches creator record with x_verified = true
   - Checks: const isCreatorVerified = creator && creator.x_verified === true
   - If verified → calls buildContextPack(supabase, creator.id)

2. BUILD CONTEXT PACK (buildContextPack)
   - Calls getProfile(supabase, creatorId)
   - Profile query filters by agentic_opt_in = true
   - When opt-in ON → profile returned
   - Fetches persona, posts, news in parallel
   - Applies token budget (≤1,000 tokens)
   - Returns populated ContextPack

3. PROMPT INJECTION (buildPersonalizedReply)
   - Receives contextPack parameter
   - Checks contextPack.persona → adds "### YOUR IDENTITY" section
   - Checks contextPack.posts → adds "### YOUR RECENT POSTS" section
   - Checks contextPack.news → adds "### RELEVANT NEWS" section
   - Injects sections into contextLines array
   - Final prompt includes all available context

EXAMPLE PROMPT (Opt-in ON):
```
Mention text: @creator what's the latest on BNB DeFi?
Context: ask intent

### YOUR IDENTITY
Bio: DeFi analyst covering BNB Chain ecosystem
Tags: defi, bnb, layer2
Interests: yield-farming, staking
Specialties: technical-analysis

### YOUR RECENT POSTS
- DeFi: BNB Chain TVL hits $5B milestone in Q1 2026...
- Layer2: opBNB processes 1M+ transactions daily...

### RELEVANT NEWS
- BNB Chain launches new staking mechanism (CoinDesk)
- DeFi protocol yields rise 15% on BNB (The Block)
```

OPT-OUT BEHAVIOR
----------------

When agentic_opt_in = FALSE:

1. CREATOR LOOKUP (lookupVerifiedCreator)
   - Fetches creator record with x_verified = true
   - Checks: const isCreatorVerified = creator && creator.x_verified === true
   - If verified → calls buildContextPack(supabase, creator.id)

2. BUILD CONTEXT PACK (buildContextPack)
   - Calls getProfile(supabase, creatorId)
   - Profile query filters by agentic_opt_in = true
   - When opt-in OFF → profile returns NULL
   - Early return with empty pack:
     ```typescript
     return {
       persona: null,
       posts: null,
       news: null,
       totalTokens: 0
     }
     ```

3. PROMPT INJECTION (buildPersonalizedReply)
   - Receives contextPack parameter (empty pack)
   - Checks contextPack.persona → NULL, skips section
   - Checks contextPack.posts → NULL, skips section
   - Checks contextPack.news → NULL, skips section
   - contextLines array has NO additional sections
   - Final prompt uses only basic context

EXAMPLE PROMPT (Opt-out OFF):
```
Mention text: @creator what's the latest on BNB DeFi?
Context: ask intent
```

GATING MECHANISM
----------------

OPT-IN GATING IMPLEMENTED AT:
- Primary gate: getProfile() in context-dal.ts (Line ~50)
  - SELECT * FROM creator_profiles WHERE creator_id = ? AND agentic_opt_in = true
  - Returns NULL when opt-in OFF
  
- Secondary gate: buildContextPack() in context-pack.ts (Line ~120)
  - if (!profile) return empty pack
  - Enforces opt-out at data layer

NO GATING IN PROCESS-MENTION:
- process-mention/index.ts does NOT check agentic_opt_in
- All gating delegated to buildContextPack
- Separation of concerns: process-mention handles routing, context-pack handles permissions
